# Design Systems (디자인 시스템)

재사용 가능한 컴포넌트, 패턴, 스타일 가이드를 모아놓은 공유된 언어입니다. 팀 전체가 일관성 있는 제품을 만들 수 있도록 합니다.

## 구성 요소
- **Design Tokens (디자인 토큰)**: 색상, 여백, 폰트 등 디자인 값의 최소 단위. 코드와 디자인 사이의 브릿지 역할
- **Component Libraries (컴포넌트 라이브러리)**: 버튼, 폼, 카드 등 재사용 가능한 UI 블록의 모음
- **Pattern Libraries (패턴 라이브러리)**: 특정 문제를 해결하기 위한 검증된 UI 패턴 모음
- **Style Tiles (스타일 타일)**: 최종 디자인 전에 분위기, 서체, 색상을 탐구하는 참고 보드

## 관련 개념
- **Atomic Design (아토믹 디자인)**: 원자(Atom) → 분자(Molecule) → 유기체(Organism) → 템플릿 → 페이지 순으로 UI를 구조화하는 방법론
- **Modular Design (모듈러 디자인)**: 독립적으로 교체 가능한 모듈 단위로 시스템을 설계하는 접근 방식
