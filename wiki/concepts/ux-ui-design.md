# UX/UI Design (UX/UI 디자인)

사용자 경험(User Experience)과 사용자 인터페이스(User Interface)를 설계하는 분야입니다.

## UX Design (사용자 경험 디자인)
사용자가 제품을 사용하는 전체 경험을 연구하고 최적화하는 과정입니다.
- **Wireframes (와이어프레임)**: 페이지 구조와 콘텐츠 배치를 뼈대 형태로 시각화한 청사진
- **Prototyping (프로토타입)**: 최종 제품 전에 인터랙션을 테스트하기 위한 시제품
- **User Flows (사용자 플로우)**: 사용자가 태스크를 완수하기까지의 단계별 경로
- **User Personas (퍼소나)**: 특정 사용자 유형을 대표하는 가상의 인물 프로필
- **Empathy Maps (공감 지도)**: 사용자의 생각, 감정, 행동을 시각화한 도구
- **Heuristic Evaluation (휴리스틱 평가)**: 전문가가 사용성 원칙에 따라 인터페이스 문제를 점검하는 방법

## UI Design (사용자 인터페이스 디자인)
화면에 표시되는 시각적 요소와 인터랙션을 설계하는 과정입니다.
- **Visual Hierarchy (시각적 위계)**: 중요도에 따라 요소의 크기, 색상, 배치를 달리하여 시선을 유도
- **Design Systems (디자인 시스템)**: 재사용 가능한 컴포넌트, 패턴, 가이드라인의 총체
- **Affordances (어포던스)**: 사용자가 어떻게 사용해야 하는지 직관적으로 알 수 있는 물체나 UI의 특성
- **Micro-interactions (마이크로인터랙션)**: 버튼 클릭 시 애니메이션 등 소소한 인터랙션 효과
- **Dark Patterns (다크 패턴)**: 사용자를 의도적으로 오도하도록 설계된 비윤리적 UI 패턴
