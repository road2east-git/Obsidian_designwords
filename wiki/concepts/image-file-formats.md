# Image File Formats (이미지 파일 포맷)

이미지를 디지털로 인코딩하는 표준화된 방식입니다. 크게 벡터와 래스터 그래픽으로 나뉩니다.

![[Image-Formats-01.avif]]

## 벡터 그래픽 (Vector Graphics)
수학적 공식을 사용하여 이미지를 표현합니다. 크기를 아무리 키워도 품질이 저하되지 않으며, 인쇄물(로고, 명함 등)에 필수적입니다.
- **AI:** Adobe Illustrator 문서 형식.
- **EPS:** 크기 조절이 가능한 벡터 포맷으로 인쇄용 로고 등에 많이 사용됨.
- **PDF:** 공유 및 프리뷰에 적합한 보편적인 포맷.

## 래스터 그래픽 (Raster Graphics)
픽셀(Pixel) 격자로 구성된 이미지입니다. 확대 시 해상도가 떨어질 수 있으며 사진 편집 등에 적합합니다.
- **JPEG:** 가장 널리 쓰이는 웹용 압축 포맷. 투명도를 지원하지 않음.
- **PNG:** 압축 시 화질 손실이 없고 투명도를 지원하여 웹에서 널리 쓰임.
- **GIF:** 애니메이션과 투명도를 지원하지만 색상 표현(256색)이 제한적임.
- **PSD:** Adobe Photoshop 원본 작업 파일.
- **TIFF:** 품질이 매우 높아 출판 및 사진 전문가들이 주로 사용하는 포맷.
