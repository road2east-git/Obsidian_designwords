# Marp (Markdown Presentation Ecosystem)

Marp는 마크다운(Markdown) 문서를 매력적인 슬라이드 프레젠테이션으로 변환해주는 오픈 소스 생태계입니다.

## 특징
- 마크다운 문법 내에 `---` 구분자를 사용하여 슬라이드를 나눕니다.
- PDF, HTML, PPTX 형식으로 출력이 가능합니다.
- Obsidian이나 VS Code 같은 마크다운 에디터와 결합하여, 노트 필기와 프레젠테이션 제작을 동시에 할 수 있는 워크플로우를 제공합니다.
