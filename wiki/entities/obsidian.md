# Obsidian

마크다운 기반 개인 지식 관리(PKM) 도구. 로컬 파일 시스템 위에서 동작하며, 양방향 링크(`[[]]`)와 그래프 뷰가 핵심 기능이다.

## Karpathy 패턴에서의 역할

- **IDE 역할**: LLM이 위키를 편집하면 사용자가 Obsidian에서 실시간으로 결과를 확인
- **그래프 뷰**: 위키의 구조와 연결 관계를 시각화
- **Web Clipper**: 웹 기사를 마크다운으로 클리핑하여 `raw/`에 저장

## 유용한 플러그인

- [[Dataview]] — 프론트매터 기반 동적 테이블/리스트
- [[Marp]] — 마크다운 슬라이드 생성
